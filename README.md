# 筑城捉鸡麻将

当前仓库包含两部分：

- 根目录网页原型：用于快速查看牌桌视觉与交互。
- `miniprogram/`：原生微信小程序前端骨架，可用微信开发者工具导入。

已确认的本地玩法见 [RULES.md](RULES.md)。

## 在微信开发者工具中预览

1. 导入本目录，工具会读取 `project.config.json`。
2. 当前配置已使用项目 AppID；在微信开发者工具中用该小程序管理员微信扫码导入。
3. AppSecret 仅放在服务端环境变量，不能写进项目或小程序代码。
4. 启动本地房间服务：`npm start`。开发者工具中需勾选“不校验合法域名”，仅用于本地联调。
5. 微信登录与真实语音需要按 `.env.example` 在部署环境配置密钥；不要把密钥写进小程序代码。

## 发布前还需要实现

- 服务端：已具备房间、长期积分、补分审计、战绩、MySQL 状态持久化、牌局恢复、骰子定座、发牌、摸打、碰、明杠、补杠/抢杠、胡牌判定、流局查听，以及观众切换第二名不同玩家后禁言的裁判逻辑。云托管环境需配置 MySQL 环境变量才能启用长期持久化。
- 微信登录：后端换取并保存用户唯一身份。
- 实时语音：当前已具备玩家/观众的后端语音权限与短期凭据接口；部署时接入合规的实时音视频服务，并在用户主动点击后请求麦克风权限。
- 管理后台：房间管理员、补 100 分记录、异常操作和对局审计。
- 真机联调、隐私合规、微信审核和发布。
